# V1 → V2 변경 내용

| 대상 | V1 원본 | V2 경량화본 |
|---|---|---|
| 추론 코드·가중치·참조 데이터 | 원본 | 그대로 유지 |
| MFA | 실행 환경과 설치·개발용 파일 포함 | 실행 환경·예열 캐시는 유지하고 설치 캐시·문서·테스트·개발용 파일 정리 |
| Transformers | 전체 모델 코드 포함 | 공통 모듈과 Whisper에 필요한 모델 코드만 부분 벤더링 |
| pip·micromamba | 설치 명령 포함 | 설치 완료 후 제거. 실행 의존성·라이선스·일부 복구 wheel은 유지 |
| 압축 레이어 | 4.187GB | 3.823GB |
| 일반 파일 내용 합계 | 6.945GB | 6.017GB |

수치는 십진 GB이고 파일 합계는 hardlink 중복을 제외합니다. RAM 수치가 아닙니다. 근거는 [이미지 제작 당시 검사 기록](https://github.com/AISWM-2PL1/Accentury_Inference/blob/v2026.10.29-kan296-0d72c03-slim.1/releases/v2026.10.29-kan296-0d72c03-slim.1/validation.json)입니다.

MFA 상주·예열 최적화는 V1에 이미 들어 있으며 V2에서 유지했습니다. Whisper 포팅·추가 학습·양자화·채점 로직 변경은 하지 않았습니다. 표본 결과 일치는 확인했지만 운영 서버 추론시간 동일성은 확인하지 않았습니다.

## 폴더를 나눈 이유

기존 main은 공통 `src/` 옆에 경량화 도구를 추가한 모양이라 원본과 경량화본을 구분하기 어려웠습니다. 현재는 `V1/`과 `V2/`에 각각 소스 사본·이미지 주소·안내를 두었습니다. 두 소스 사본은 같은 원본 커밋과 비교하고, V2 빌드·검사 코드는 기존 게시 커밋과 비교합니다.

이 정리는 새 이미지를 만든 작업이 아닙니다. 기존 이미지 digest·Git tag·GitHub Release는 유지하며 과거 폴더 구조와 체크섬은 [기존 태그의 전체 스냅샷](https://github.com/AISWM-2PL1/Accentury_Inference/tree/v2026.10.29-kan296-0d72c03-slim.1)에 남아 있습니다.
