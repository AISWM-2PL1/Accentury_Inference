# Accentury Inference

**V1은 MFA 최적화 원본, V2는 V1의 용량을 줄인 버전입니다.** 아래 폴더에서 각 버전의 코드·이미지·실행 안내를 볼 수 있습니다.

| 버전 | 무엇이 다른가 | 압축 이미지 | 압축 전 파일 |
|---|---|---:|---:|
| **[V1 · 원본](V1/README.md)** | KAN-296 MFA 상주·예열 최적화가 들어간 원본 | 4.19GB | 6.94GB |
| **[V2 · 경량화본](V2/README.md)** | V1에서 불필요 파일 제거·Transformers 부분 벤더링 | 3.82GB | 6.02GB |

```text
V1/  원본 코드 + 원본 이미지 주소 + 실행 안내
V2/  경량화본 코드 + 경량 이미지 주소 + 빌드·검사 + 변경 내용
```

두 버전의 추론 소스와 모델 가중치는 같습니다. V2는 이미지에 들어 있는 라이브러리·설치 캐시·개발용 파일 구성을 줄였습니다. 버전별로 바로 열어볼 수 있도록 소스 사본도 각 폴더에 넣었습니다.

V2 제작 때 실제 음성 6건을 포함한 18사례의 **시간 외 결과가 같았고**, 운영 서버 추론시간·RAM·동시성은 미검증입니다. 폴더를 나누면서 이미지를 다시 만들거나 운영 서버를 배포하지 않았습니다. 용량은 십진 GB이며 압축 레이어와 hardlink 중복을 뺀 일반 파일 내용 합계입니다.
